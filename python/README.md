# Python Data Processing

This folder contains Python scripts for processing and validating EPC project control data.

## Objectives

- Load project data from CSV files.
- Validate WBS codes and data consistency.
- Check missing values and invalid progress percentages.
- Prepare clean datasets for Power BI.
- Support future project performance calculations.

## Project Data Sources

The scripts use the following files:

- `data/sample/wbs.csv`
- `data/sample/budget.csv`
- `data/sample/progress.csv`
- `data/sample/actual_costs.csv`

## Planned Scripts

- `validate_data.py` — data loading and validation.
- `calculate_performance.py` — project performance calculations.

All datasets are fictional and created for educational purposes.
